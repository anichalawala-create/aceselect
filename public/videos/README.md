# Video & Image Assets for Ace Select Website

## Hero Video
Place your hero billboard video here as:
- `/public/videos/hero-billboard.mp4` (primary, H.264 compressed)
- `/public/videos/hero-billboard.webm` (optional, WebM format for better compression)

## Hero Poster (fallback image for mobile / slow connections)
- `/public/images/hero-poster.jpg` (a still frame from the video, ~1920×1080)

## Asset Requirements
- Video: Max 10MB recommended for web delivery. Use H.264 encoding, muted, loop, autoplay.
- Poster: JPEG, 80% quality, 1920×1080px or similar widescreen ratio.

## Current Placeholders
The site currently uses Unsplash placeholder images for all portfolio galleries and service pages.
To replace: swap the image URLs in the respective page components.
